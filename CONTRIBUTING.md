# Contributing

## Principles

Contributions must preserve provenance, version information and license classification.

## Workflow

1. Create a branch.
2. Add or update structured data.
3. Run the relevant validator.
4. Regenerate documentation and portal datasets.
5. Run `mkdocs build --strict`.
6. Open a pull request describing sources and methodology.

## Do not submit

- unsupported marketing claims;
- copied third-party implementations without permission;
- benchmark results without model versions and sources;
- synthetic data presented as real evidence;
- secrets, credentials or personal data.
