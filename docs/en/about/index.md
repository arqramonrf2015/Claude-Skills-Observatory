# About

The Claude Skills Observatory is an independent open-source documentation project created by **Ramon Ribeiro Fontes**.

## Editorial principles

- evidence before claims;
- explicit provenance;
- exact versions and dates;
- clear distinction between official, community, estimated and synthetic data;
- reproducible transformations;
- accessible multilingual documentation;
- no paid infrastructure requirement.
