# Agent Skills

Agent Skills are self-contained folders that provide specialized instructions and optional resources for repeatable tasks.

## Catalog principles

- verify every source path;
- record the exact upstream blob SHA;
- distinguish official, partner, community and custom skills;
- preserve licensing notices;
- avoid copying complete upstream implementations;
- generate indexes from structured data.
