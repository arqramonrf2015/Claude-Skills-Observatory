# Agent Skills

Agent Skills são pastas independentes que fornecem instruções especializadas e recursos opcionais para tarefas repetíveis.

## Princípios do catálogo

- verificar o caminho de cada fonte;
- registrar o hash exato do arquivo upstream;
- distinguir Skills oficiais, de parceiros, comunitárias e personalizadas;
- preservar os avisos de licença;
- evitar copiar integralmente implementações externas;
- gerar índices a partir de dados estruturados.
