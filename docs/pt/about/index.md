# Sobre

O Claude Skills Observatory é um projeto independente e open source de documentação criado por **Ramon Ribeiro Fontes**.

## Princípios editoriais

- evidências antes de afirmações;
- procedência explícita;
- versões e datas exatas;
- distinção clara entre dados oficiais, comunitários, estimados e sintéticos;
- transformações reproduzíveis;
- documentação multilíngue e acessível;
- nenhuma exigência de infraestrutura paga.

## Independência

Este projeto não é uma publicação oficial da Anthropic. Nomes de produtos e marcas pertencem aos respectivos titulares.
